# 🌐 Skill Exchange Platform
Live Demo-skill-swap-7815f0.netlify.app
> **Software Engineering Mini Project**  
> A responsive, frontend-only web application where users across all age groups can discover, share, and exchange technical and creative skills.

---

## 🚀 Tech Stack

| Technology | Purpose |
| :--- | :--- |
| **HTML5 & CSS3** | Semantics, custom layout styling, and responsiveness |
| **JavaScript (ES6+)** | Dynamic behavior, form control, and interactive logic |
| **Bootstrap 5** | Responsive grid, form templates, and UI components |
| **Font Awesome** | Vector icons for visual navigation |

---

## ✨ Core Application Modules

*   **🏠 Home Page:** Features a search bar for skills, user reviews, testimonials, and an FAQ accordion.
*   **👤 Profile Builder:** Form module allowing users to input personal details, bio, availability schedules, and list "Skills Offered" vs "Skills Wanted."
*   **🌍 Community Hub:** A directory of member profiles designed as interactive cards with real-time "Request Exchange" prompts.
*   **🧩 Categories Display:** Organized filtering layouts separating Technical, Non-Technical, and Creative skill groups.
*   **📅 Meeting Scheduler:** A frontend interface to plan, schedule, and confirm mock virtual learning classroom slots.

📊 Software Development Life Cycle (SDLC) 
1️⃣ Requirements & Design
Functional: Profile editing, keyword skill searches, mock community requests, and class scheduling.

UI/UX Design: Built on a blue gradient theme utilizing a mobile-first Bootstrap grid layout with card hover interactions.

2️⃣ Implementation & Modules
Semantic markup linked with modular CSS stylesheets.

JavaScript handles responsive state updates, button clicks, and simulated form submissions.

3️⃣ Testing & Deployment
Scope: Cross-browser compatibility verified on Chrome, Edge, and Firefox. Validation of mobile layouts and interactive buttons.

Deployment Ready: Optimally configured for static host setups like GitHub Pages, Netlify, or Vercel.

🔒 Limitations & Future Scope
Because this is a frontend-only prototype, data does not persist beyond browser refreshes. Future enhancements will integrate:

User authentication (JWT/OAuth)

A dedicated backend API and database (Node.js/Express + MongoDB)

Real-time chat, actual video conferencing rooms, and an AI-based skill matching engine.
